# CYBERLIFE — textes du jeu

Ce dépôt permet de proposer des corrections aux textes français et anglais de CYBERLIFE, sans accès au code du jeu.

Le fichier à modifier est [TEXTES.txt](TEXTES.txt). Il contient les messages affichés aux joueurs. Une entrée commence par `[clé]`, suivie de lignes `fr` et `en`. Gardez les clés, les variables entre accolades (`{name}`, `{amount}`), les commandes entre accents graves et les séquences `\n` : le jeu en a besoin pour afficher les messages correctement.

Pour contribuer, ouvrez une *issue* pour signaler un passage confus, ou proposez une *pull request* avec votre correction. Indiquez les clés concernées et, si possible, le contexte dans lequel le texte apparaît. Les changements seront relus avant d'être intégrés au jeu ; modifier ce dépôt ne change pas immédiatement les textes en production.

Le catalogue et les noms du jeu appartiennent à leurs ayants droit. Ce dépôt est destiné aux contributions éditoriales pour CYBERLIFE.

## English

This repository is for French and English text corrections to CYBERLIFE. Edit [TEXTES.txt](TEXTES.txt), keeping entry keys, placeholders such as `{name}`, commands in backticks, and `\n` sequences intact. Open an issue to report unclear text, or submit a pull request with your proposed wording and the relevant entry keys. Changes are reviewed before they are added to the game.
